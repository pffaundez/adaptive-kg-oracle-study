# adaptive-kg-oracle-study

Estudio reproducible para validación, reward y cálculo del oracle en Adaptive KG Routing.

## Estructura

- `configs/`: workflows y parámetros experimentales.
- `data/`: manifiestos, datos normalizados y ejemplos.
- `results/`: resultados generados.
- `scripts/`: comandos reproducibles.
- `src/oracle_study/`: validación, reward y cálculo del oracle.
- `tests/`: pruebas.
